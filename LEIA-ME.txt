PIXELMON COLMÉIA — VERSÃO MULTIPÁGINA PARA GITHUB PAGES

1. Extraia este ZIP.
2. Crie um repositório GitHub e envie TODOS os arquivos HTML e este README para a raiz.
3. Abra Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. O link do Discord foi atualizado em todo o site para https://discord.gg/XtrxqZmdn.

PÁGINAS: index.html (início e VIPs), loja.html, pokemons.html, checkout.html, boosters.html, creators.html e carta.html.

BOTÕES: menu mobile abre/fecha; links levam a páginas; carrossel VIP tem setas, pontos e avanço automático; adicionar produto atualiza carrinho; carrinho abre checkout; checkout baixa resumo de pedido.

LIMITAÇÕES: login Google é apenas demonstrativo até configurar Firebase Authentication. Não digite senha Google na página. O Pix é exibido conforme informado, mas não há validação automática de pagamento nem entrega automática. Cupons não estão cadastrados.
